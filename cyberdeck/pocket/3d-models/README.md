# 3D Models — CyberDeck Pocket

STL files for the PSP Go-style pocket enclosure.

## Getting These Printed

Find someone with a 3D printer — a friend, local makerspace, or a printing service — and share the specs from [`docs/3d-printing.md`](../docs/3d-printing.md). Total print time is ~8 hours using about 200g of filament. They can run it overnight.

## Parts

| File | Description |
|------|-------------|
| `bottom-shell.stl` | Main body — holds Pi Zero 2 W, battery, side buttons |
| `top-shell.stl` | Screen bezel and top panel |
| `keyboard-plate.stl` | 44-key thumb keyboard mounting plate |
| `button-cap.stl` | Side action button caps (print × 4) |

> STL files coming soon — community designs welcome. Fork and submit a PR!

## Size Reference

Designed to be held in two hands and typed with thumbs:

- **Overall: 160 × 85 × 25mm**
- Slightly wider than a PSP Go (128 × 69 × 16.5mm) to fit the keyboard
- About the size of a large smartphone, but thicker
- Fits in a jacket pocket or a cargo pocket
